👋 Bienvenue dans MyTaskManager

📋 Gestion de tâches

Organisez vos tâches en arborescence infinie : chaque tâche peut contenir des sous-tâches, accessibles via un clic sur 📋.

  • Prioriser : cliquez sur une tâche pour la faire remonter en tête de liste. Plusieurs clics rapides cumulent.
  • Réordonner : glissez-déposez les tâches dans la liste ou vers un nœud de l'arborescence (sidebar).
  • Notes riches : dans la vue détail, éditez des notes avec texte formaté, listes, liens…
  • Rechercher : la barre de recherche explore le niveau courant ou toute l'arborescence, titres et notes.

🌳 Arborescence (sidebar)

La sidebar gauche affiche l'arborescence complète. Cliquez sur un nœud pour y naviguer. Le nœud racine 🏠 affiche toutes les tâches de premier niveau. La sidebar est redimensionnable et peut être masquée.

☁️ Synchronisation (optionnelle)

Vos données sont toujours sauvegardées localement (localStorage). La sync via GitHub Gist est optionnelle et vous permet d'accéder à vos tâches depuis plusieurs appareils (PC, smartphone…).

Pour activer la sync :

  1. Créez un GitHub Gist vide (secret) sur gist.github.com.
  2. Générez un Personal Access Token avec la portée gist sur github.com/settings/tokens.
  3. Cliquez sur ⚙ en haut à droite, activez la sync et renseignez le token et l'ID du Gist.

La synchronisation est bidirectionnelle (merge automatique) et fonctionne en arrière-plan. Elle se déclenche aussi si vous êtes actif et que la dernière sync date de plus de 10 minutes. Vous pouvez aussi cliquer sur l'indicateur de statut (⚫/🟢/🔴) pour forcer une sync immédiate.
